# 04: Neural Forensic Suite

### Overview
Surgical auditing of academic manuscripts for linguistic anomalies and AI-generated signatures.

### Core Logic
- **Engine**: `useRigor.js` utilizing a memoized Trie (450k+ words).
- **AI Diagnostics**: GPT-2 v6.2 (Perplexity, Burstiness, and Top-K Forensic Profiling).
- **High-Rigor Detection**: Specific heuristics for 'Genius AI' profiles (Gemini/DeepSeek calibration).
- **UI Interaction**: "Zero-Shift" grid stacking and Mobile Responsive Stacking (v2.0).
- **Feedback**: 4-section diagnostic cards and High-Density Mobile Analytics.
- **Constraint**: Must never reflow paragraphs during an active audit.
