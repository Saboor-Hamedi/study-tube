# 06: AI Dialogue Bridge

### Overview

Integrated research-native chat system using DeepSeek/Local models for contextual synthesis.

### Core Logic

- **Communication**: Streaming responses for low-latency dialogue.
- **Context**: Automatic injection of research library fragments into the forensic prompt.
- **UI**: High-density message history with code-highlighting and industrial markdown support.
- **Security**: Local-first context processing to maintain data sovereignty.
