# 00: Feature Status Manifest

### ✅ COMPLETED (Production Ready)
- **Neural Forensic Suite**: The WritingView, `useRigor` engine, and Zero-Shift canvas.
- **AI Signature Analysis**: Local GPT-2 transformer service (Perplexity & Burstiness).
- **Research Archival**: YouTube transcript extraction and metadata harvesting.
- **Persistence Layer**: PostgreSQL-backed research vault with FTS & Trigram search.
- **AI Dialogue Bridge**: DeepSeek-integrated chat with contextual research injection.
- **Industrial HUD**: Surgical menu positioning and diagnostic anomaly cards.

### ⏳ PENDING (In Progress / Roadmap)
- **Neural Feedback Hub**: Granular interactive auditing for multi-document manuscripts.
- **Contextual Synthesis**: Automated generation of draft chapters from research fragments.
- **Hybrid Cloud Sync**: Finalizing real-time parity between local DB and cloud endpoints.
- **Mobile Companion**: Porting the research vault to a sovereign mobile interface.
- **Advanced Plagiarism**: Expanding the local heuristic database for academic integrity.

### 🚫 OUT OF SCOPE (Will Not Implement)
- **External Data Leaks**: Sending manuscript data to public LLM APIs for forensic detection.
- **Collaborative Editing**: Real-time multi-user editing (Conflicts with "Sovereignty First" ethos).
- **Legacy Support**: Supporting browsers older than 2023 (Targeting high-performance Web/Electron).
- **Plugin Marketplace**: Allowing unvetted third-party scripts to access the forensic core.
